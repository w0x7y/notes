# Main UI mockup

Open `main-ui.html` directly in a browser. It has no dependencies or network requests.

This is a disposable visual mockup with illustrative notes, not the app implementation. The toolbar toggle, preview toggle, split toggle, search popup, and folder expansion work. Ctrl+P opens search; Escape closes it. Search filters a small sample list. Other file navigation, formatting commands, editing, saving, image viewing, and workspace switching are not implemented.

The palette comes from [One Dark Pro](https://github.com/Binaryify/OneDark-Pro/blob/master/themes/OneDark-Pro.json): editor `#282c34`, sidebar `#21252b`, text `#abb2bf`, selection `#2c313a`, blue `#61afef`, purple `#c678dd`, green `#98c379`, yellow `#e5c07b`, red `#e06c75`.

The production stack remains Tauri, React, TypeScript, and Tailwind. This single-file sketch is intentionally independent of that setup.
