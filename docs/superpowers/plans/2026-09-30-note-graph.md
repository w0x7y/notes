# Hierarchical note graph implementation plan

**Goal:** Replace the disposable 30-concept page with a working circular hierarchical edge-bundling graph and a persisted bundling-strength setting.

**Architecture:** A lazy graph dialog reuses the optional content-analysis cache and existing note-link resolution. Workspaces, nested folders, and Markdown notes form a deterministic hierarchy. Small D3 hierarchy/shape modules calculate radial positions and bundled SVG paths; React owns interactions. Layout depends on file metadata, not text queries or parsed-content arrivals. Native settings validate and persist strength separately from note contents.

**Constraints:** Preserve One Dark Pro, keyboard navigation, popup autofocus, mixed-language labels, save queues, and existing note-link semantics. No new file commands, background scans, or writes to note contents. Default bundling is 0.85, with values from 0 to 1. Both current-workspace and all-workspace views are available. Unreadable notes remain visible and incomplete links are reported. Missing and ambiguous targets do not become fabricated edges.
